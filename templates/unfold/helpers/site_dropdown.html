{% comment %} Project override of unfold 0.99.1's unfold/helpers/site_dropdown.html. Used as the active-company switcher. Several companies can be active at once, so items behave like checkboxes — but checking/unchecking one used to POST immediately (admin:company_switch_active), forcing a full page reload — and the dropdown closing — on every single click. Now checking items only flips local Alpine state (no reload) inside ONE form; nothing is submitted until "Apply" POSTs the whole pending selection at once to admin:company_switch_active_apply. Note: icon/label toggling uses x-show, not Tailwind's peer-checked:/has-[] variants — Unfold ships a precompiled CSS bundle (not a JIT compiler), and those exact utility strings aren't used anywhere in its vendor templates, so they wouldn't be in the bundle and would silently no-op.
